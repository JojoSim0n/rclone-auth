Privacy Policy

This OAuth client application is used solely by its owner for personal rclone backups and file management.

  • Data Collection: No third-party data is collected, stored, or shared.
  • Data Access: The application only transfers files between the owner's configured storage providers and local device based on explicit manual or automated commands.
  • Data Retention: Authentication tokens are stored securely on the user's local machine and can be revoked at any time via the provider's security settings.
